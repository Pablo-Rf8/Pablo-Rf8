## Tarjetas de actividad

`scripts/refresh-profile-cards.mjs` actualiza las tarjetas públicas de **Pablo-Rf8** y conserva la última versión válida si el servicio falla. No combina estadísticas con 0ghost8.

El workflow corre al modificar el README o el script, manualmente desde Actions y una vez al día, a las 09:37 UTC (GitHub puede retrasar ejecuciones).

El `GITHUB_TOKEN` temporal se usa para publicar los archivos en este repositorio. No se envía al servidor de tarjetas y no requiere un token personal. Las estadísticas solo incluyen repositorios públicos.
